# Line-E

This is my next line follower design. After our team won first place in the seniors line follower category at TechnoXian Egypt and qualified for the World Cup in Malaysia, I wanted to try a new robot built around a standalone microcontroller.

## The plan

- A custom PCB with a bare ATmega328P that I'll solder myself
- A 14-sensor IR array for reading the line
- A new design aimed at competing at world level

This repo is at the planning stage and currently only has this README. I'll add the circuit, CAD, and firmware as the design develops.

The earlier build is here: [Line Follower Bot](https://github.com/ZIZO932/Line-follower-Bot).
